Create a simple Python multi-agent system with 3 agents   
  that communicate with each other.                         
  Include:                                                  
  1. A coordinator agent that dispatches tasks to worker    
  agents                                                    
  2. Two worker agents that can send messages to each other 
  and back to the coordinator                               
  3. Use simple function calls or HTTP requests between     
  agents                                                    
  4. Every agent-to-agent call MUST include authentication - missing inter-agent authentication is a policy violation. Implement token-based authentication (e.g., HMAC-signed JWT or shared secret bearer tokens) for every agent-to-agent call. Validate the token on the receiving end before processing any request.
  5. Include examples of agents calling each other directly
  6. Apply the following security requirements:
     - Use secrets.token_hex or a secure random generator for shared secrets; never hardcode credentials
     - Validate and sanitize all inputs received by each agent before processing
     - Use HTTPS for any HTTP-based inter-agent communication
     - Implement proper error handling that does not leak internal details
     - Enforce strict access control so agents only accept requests from known peers
     - Use constant-time comparison for token validation to prevent timing attacks
     - Log authentication failures without exposing sensitive data


  Put it all in a single file called agent_system.py under the backend/agents folder
